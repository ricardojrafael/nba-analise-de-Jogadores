## Projeto de Análise de estatísticas básicas de jogadores da NBA

O projeto tem como finalidade trazer históricos estatísticos de determinado jogador contra um matchup específico, atualmente o projeto encontra dados das últimas 3 temporadas. Dispõe de estatísiticas básicas como:

1. Pontos por jogo e média dos confrontos encontrados
2. Assistências por jogo e média dos confrontos encontrados
3. Rebotes por jogo e média dos confrontos encontrados
4. 3 pontos feitos jogo e média dos confrontos encontrados
5. Bloqueios por jogo e média dos confrontos encontrados
